# PA1 — 3D Shapes in WebGL

- **Student ID:** [243122]
- **Variant:** 22
  - **Assigned Solid:** Wedge (Ramp)
  - **Offset Direction:** (+0.15, -0.15)

## How to Run
Serve the repository using a local web server (e.g., Live Server in VS Code or `python -m http.server 8000`). Open `index.html` in Chrome or Firefox.

## Key Controls
- `1`: gl.TRIANGLES
- `2`: gl.LINE_LOOP
- `3`: gl.LINES
- `4`: gl.LINE_STRIP
- `5`: gl.POINTS
- `6`: gl.TRIANGLE_STRIP
- `D`: Toggle Depth Testing (ON/OFF)
- `S`: Swap Draw Order (Cube First / Wedge First)
